# Task2. Оценка готовности данных, размещения и выбор модели

Состав директории:

- `01_data_readiness.md` — оценка готовности данных по трём инициативам по чек-листу паспорта (раздел 4), с вердиктами и
  указанием точного дефицита.
- `02_placement_and_model_selection.md` — выбор размещения (пилот / целевой прод), шортлист моделей под выходной
  контракт, процедура приёмки шортлиста.
- `03_adr_001_suspicious_operations.md` — сквозной ADR по флагману: контекст, жёсткие ограничения, варианты, решение по
  данным, размещению и модели, допущения, риски, план выхода от вендора, триггеры пересмотра, история версий.
- `04_passport_sections_2-5_flagman.md` — разделы 2–5 паспорта для инициативы №1.
- `05_passport_sections_2-5_documents.md` — разделы 2–5 паспорта для инициативы №18.
- `06_passport_sections_2-5_routing.md` — разделы 2–5 паспорта для инициативы №5.

## Ключевые решения Task2 (кратко)

| Вопрос                             | Решение                                                                                                                                                                                                   |
|------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Путь получения сигнала по флагману | Слабые метки (эскалация, исход расследования) для первичного обучения + вероятностная контрольная выборка, размечаемая экспертами, для честной оценки и постепенного накопления сильных меток.            |
| Что строим по флагману             | Сервис приоритизации очереди ручной проверки, а не классификатор «схема / не схема».                                                                                                                      |
| Размещение (пилот)                 | On-premises / защищённый контур банка для инференса и данных.                                                                                                                                             |
| Размещение (целевой)               | Гибрид по звеньям: данные и скоринг — в контуре банка; LLM/OCR-компоненты, не видящие персданные в открытом виде, — допускаются в выделенном контуре провайдера только после заключения комплаенса и DPO. |
| Данные (флагман)                   | Разрыв с планом закрытия: нет эталона, есть смещение отбора. Закрывается программой разметки, а не покупкой данных.                                                                                       |
| Данные (№18)                       | Можно начинать пилот.                                                                                                                                                                                     |
| Данные (№5)                        | Можно начинать пилот.                                                                                                                                                                                     |
