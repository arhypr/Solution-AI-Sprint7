# План мониторинга

## Флагман

| Слой    | Что отслеживаем                   | Метрика / порог                                       | Действие                                             |
|---------|-----------------------------------|-------------------------------------------------------|------------------------------------------------------|
| Вход    | Схема и полнота данных            | доля записей с пропусками, `is_stale`                 | Рост → алерт, фолбэк                                 |
| Вход    | Дрейф признаков                   | PSI по ключевым признакам                             | PSI > порога → проверка, кандидат на переобучение    |
| Вход    | Распределение текста назначения   | доля OOD-текстов                                      | Рост → разбор, обновление эмбеддингов                |
| Модель  | Распределение скора               | среднее, квантили, доля в зоне воздержания            | Сдвиг → проверка калибровки                          |
| Модель  | Калибровка                        | Brier score на контрольной выборке                    | Ухудшение → перекалибровка                           |
| Модель  | Качество                          | precision@K, yield@K на контрольной выборке           | Падение ниже baseline → пересмотр (триггер ADR)      |
| Модель  | Стабильность                      | доля фолбэков по причинам                             | Рост `model_unavailable` → инцидент                  |
| Очередь | Глубина и SLA                     | длина очереди, время ожидания, throughput             | Рост ожидания → пересмотр K и порогов                |
| Очередь | Решения человека                  | доля override скора, причины                          | Высокий override → разбор, возможен пересмотр модели |
| Бизнес  | Ложные блокировки                 | доля приостановок, снятых после разбора; жалобы       | Ухудшение → guardrail-алерт                          |
| Бизнес  | Пропущенные подтверждённые случаи | случаи, подтверждённые позже и не попавшие в верхушку | Рост → пересмотр приоритизации                       |
| Аудит   | Воспроизводимость                 | наличие версии модели и фичей по каждому решению      | Пропуск → инцидент                                   |

**Что запускает повторную проверку:** падение precision@K ниже baseline; рост доли override; рост ложных блокировок; PSI
выше порога; смена доли фолбэков.

**Что запускает откат:** деградация guardrail (ложные блокировки/жалобы хуже baseline); критическая ошибка контракта;
недоступность модели дольше согласованного окна → работа только на правилах.

## №5

| Слой    | Что                                             | Действие                |
|---------|-------------------------------------------------|-------------------------|
| Вход    | Доля пустых/неразборчивых текстов               | Алерт                   |
| Модель  | macro-F1, top-3 на контрольной выборке          | Падение → дообучение    |
| Очередь | Доля low-confidence, длина ручной сортировки    | Рост → пересмотр порога |
| Бизнес  | Время до первого ответа, доля перемаршрутизаций | Ухудшение → пересмотр   |

## Общее

Мониторинг покрывает не только качество модели, но и вход, очередь человека и бизнес-метрику. Без контрольной выборки
оценка качества была бы смещена: она мерила бы только то, что модель уже отобрала.
