# Уровень автоматизации и фолбэк

## Флагман

### Уровень автоматизации

| Что                         | Уровень                                                   |
|-----------------------------|-----------------------------------------------------------|
| Расчёт скора и приоритета   | Автоматически                                             |
| Срабатывания правил         | Автоматически                                             |
| Постановка в очередь        | Автоматически (действие обратимо, не затрагивает клиента) |
| Эскалация на расследование  | **Только человек**                                        |
| Отказ в проведении операции | **Только человек**                                        |
| Снятие с контроля           | **Только человек**                                        |
| Автоматическая блокировка   | **Не делаем**                                             |

Порог top-K увязан с пропускной способностью: K ≈ 10 тыс. операций/мес, которые служба физически разбирает. Модель не
расширяет поток решений за пределы мощности человека.

### Фолбэк-триггеры (наблюдаемые)

| Триггер                             | Условие                                 | Куда уходим                     |
|-------------------------------------|-----------------------------------------|---------------------------------|
| Нет или устарели признаки           | `features_age_sec` > порога, пропуски   | Правила + сумма, ручной разбор  |
| Клиент/сегмент без истории          | Нет истории в окне                      | Ручной разбор                   |
| Значение вне распределения обучения | OOD-детектор                            | Ручной разбор                   |
| Зона воздержания                    | Скор около порога                       | `review_normal` + ручной разбор |
| Расхождение правила и модели        | Правило «да», модель «нет» (и наоборот) | Ручной разбор с флагом          |
| Модель недоступна                   | Таймаут/ошибка                          | Только правила                  |
| Сервис признаков недоступен         | Ошибка                                  | Правила по сырым полям          |
| Отказ внешнего KYC                  | Ошибка/лимит                            | Скор без сигнала KYC, флаг      |
| Превышение лимитов                  | Rate limit                              | Очередь по правилам, инцидент   |

## №18

| Что                        | Уровень                                                             |
|----------------------------|---------------------------------------------------------------------|
| OCR и извлечение           | Автоматически                                                       |
| Запись значения в карточку | Автоматически только при высокой уверенности и пройденных проверках |
| Критическое поле           | **Только с подтверждением андеррайтера**                            |
| Кредитное решение          | **Только человек**                                                  |

Фолбэк: не прошла схема ответа; нет подтверждающего фрагмента; документы противоречат друг другу; документ вне области
применимости; LLM недоступна → остаётся layout-модель; OCR недоступен → документ в ручной разбор.

## №5

| Что                                       | Уровень                  |
|-------------------------------------------|--------------------------|
| Маршрутизация при уверенности выше порога | Автоматически (обратимо) |
| Low-confidence                            | Ручная сортировка        |
| Перемаршрутизация                         | Человек                  |

Фолбэк: не прошла схема; отдел вне справочника; пустой/неразборчивый текст; LLM недоступна → классификатор;
классификатор недоступен → правила по ключевым словам; внешний канал недоступен → буфер.

## Общее для всех

Отказ внешнего сервиса и превышение лимитов → деградация на детерминированные правила или ручной разбор, инцидент в
мониторинг. Система не «падает в отказ» молча: каждое срабатывание фолбэка логируется с причиной.
