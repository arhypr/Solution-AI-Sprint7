# Таблица ответственности компонентов

## Флагман

| Компонент / контейнер       | Код / модель / очередь / человек | Ответственность                                       | Что НЕ делает                   |
|-----------------------------|----------------------------------|-------------------------------------------------------|---------------------------------|
| Ingestion & Feature Builder | Код                              | Нормализация операции, признаки, эмбеддинги текста    | Не принимает решений            |
| Feature Store               | Хранилище                        | Онлайн/офлайн признаки, версии                        | —                               |

| Рабочее место ФМ            | **Человек**                      | Разбор, эскалация, отказ, снятие по процедуре         | —                               |
| Control Sample Generator    | Код                              | Стратифицированная случайная выборка                  | Не отбирает по модели           |
| Label Store                 | Хранилище                        | Разметка очереди + контрольной выборки                | —                               |
| Training Pipeline           | Код + обучение                   | Обучение, валидация, калибровка                       | Не влияет на онлайн-путь        |
| Model Registry              | Хранилище                        | Версии, происхождение                                 | —                               |
| Monitoring & Audit          | Код                              | Метрики, аудит, триггеры                              | —                               |
