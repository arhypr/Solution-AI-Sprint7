# C4 Container — инициатива №5: маршрутизация обращений

## Назначение

Направить обращение в очередь нужного отдела; low-confidence — на ручную сортировку.

## Диаграмма

C4 Container — `diagrams/04_container_routing.puml`. Границы доверия [TB-A]…[TB-D] помечены на связях.

## Контейнеры и их роли

| Контейнер           | Тип              | Роль                                                                  |
|---------------------|------------------|-----------------------------------------------------------------------|
| Channel Connectors  | Сервис           | Приём обращений, нормализация, маскирование ПДн.                      |
| Preprocessor        | Сервис           | Очистка текста, язык, дедупликация.                                   |
| Classifier (RuBERT) | Сервис с моделью | Вероятности по отделам, top-1/top-3.                                  |
| LLM Fallback        | Сервис с моделью | Классификация сложных формулировок, только low-confidence.            |
| Routing Rules       | Сервис           | Правила по каналу, типу клиента, ключевым словам, справочник отделов. |
| Router & Contract   | Сервис           | Стык модели и правил, порог, контракт.                                |
| Manual Sort Queue   | Очередь          | Обращения с низкой уверенностью.                                      |
| Monitoring          | Сервис           | macro-F1, доля перемаршрутизаций, время до ответа.                    |
| Label Store         | Хранилище        | История маршрутов и правок оператора.                                 |

## Границы доверия

| Метка | Граница                                                                              |
|-------|--------------------------------------------------------------------------------------|
| TB-A  | Текст обращения клиента (недоверенный контент) входит в препроцессор и классификатор |
| TB-B  | Передача текста в LLM (если LLM вынесена за контур)                                  |
| TB-C  | Выход в CRM: тикет в очереди отдела                                                  |
| TB-D  | Логи и телеметрия                                                                    |

## Режим и автоматизация

- **Real-time**, синхронно на обращение; таймаут → фолбэк на правила.
- Модель только предлагает отдел; при уверенности выше порога тикет ставится в очередь автоматически (действие
  обратимо), при низкой — в ручную сортировку.
- Правовых последствий для клиента нет; цена ошибки — задержка.
