# C4 Container — инициатива №18: извлечение финансовых показателей из документов

## Назначение

Предзаполнить карточку кредитной заявки: извлечь значения полей из документов и подсветить низкую уверенность.
Андеррайтер подтверждает или правит.

## Диаграмма

C4 Container — `diagrams/03_container_documents.puml`. Границы доверия [TB-A]…[TB-E] помечены на связях.

## Контейнеры и их роли

| Контейнер               | Тип                          | Роль                                                                        |
|-------------------------|------------------------------|-----------------------------------------------------------------------------|
| Document Ingestion      | Сервис                       | Приём PDF, сканов, Excel, фото; антивирус; нормализация.                    |
| OCR Service             | Сервис/ML-движок             | Распознавание текста, координаты.                                           |
| Extraction Service      | Сервис с моделью             | Layout-модель: извлечение пар «показатель → значение», тип документа.       |
| LLM Fallback            | Сервис с моделью             | Доизвлечение на нетиповых документах, только low-confidence.                |
| Field Validator         | Сервис                       | Обязательность полей, арифметические контроли, сверка со справочником форм. |
| Card Builder & Contract | Сервис                       | Сборка карточки, уверенность, ссылки на фрагменты, валидация контракта.     |
| Verification UI         | Существующий UI андеррайтера | Подтверждение/правка значений.                                              |
| Label Store             | Хранилище                    | Исправления андеррайтера как слабая разметка.                               |
| Training Pipeline       | Пакетный сервис              | Обучение layout-модели.                                                     |
| Model Registry          | Хранилище                    | Версии модели.                                                              |
| Monitoring              | Сервис                       | Качество извлечения, доля правок.                                           |

## Границы доверия

| Метка | Граница                                                                    |
|-------|----------------------------------------------------------------------------|
| TB-A  | Недоверенный документ клиента (PDF/скан/фото) входит в OCR и layout-модель |
| TB-B  | Передача фрагмента в LLM (если LLM вынесена за контур банка)               |
| TB-C  | Артефакты модели и зависимости                                             |
| TB-D  | Выход в карточку андеррайтера и в кредитный процесс                        |
| TB-E  | Исправления андеррайтера → training pipeline                               |

## Режим обработки и автоматизация

- Обработка **пакетная/асинхронная** при загрузке пакета: OCR и извлечение занимают секунды–минуты, человек ждёт
  карточку, а не блокируется.
- **Автоматизация:** модель извлекает и предлагает значения; детерминированный `Field Validator` отсекает арифметически
  невозможное; **андеррайтер подтверждает каждое критическое поле**. Автоматической записи в кредитное решение нет.
- **LLM Fallback** подключается только на low-confidence и только для обезличенных фрагментов.
